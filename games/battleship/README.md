# Battleship Pacific

HTML, CSS ve JavaScript ile çalışan zeeslag oyunu.

## Dosyalar

- `index.html`: Başlangıç, ülke seçimi ve oyun ekranları.
- `style.css`: Oyunun görünümü.
- `script.js`: Ülke seçimi, gemi yerleştirme, atışlar ve bilgisayarın hamleleri.
- `*flag.png`: Ülke bayrakları.

## Oynama

Start düğmesine bas, iki farklı ülke seç ve Continue to Game ile ilerle.
Beş gemiyi kendi tahtana yerleştir. Rotate Ship ile gemiyi döndürebilirsin.
Start Battle düğmesinden sonra rakibin tahtasına tıklayarak atış yap.

## Bu sürüm

HTML'de bulunmayan bayrak elemanlarına yapılan JavaScript referansları kaldırıldı.
Bayraklar oyun tahtalarının başlıklarında gösteriliyor. Türkiye bayrağının dosya yolundaki fazladan boşluk temizlendi.
Kaynak depoda ses dosyası ve müzik düğmesinin işlevi bulunmadığı için kullanılmayan müzik etiketleri kaldırıldı.
